## 비바마켓 · Beaten by the Market

> 시장에 지지 않기 위해 공시 원문을 풀어서 읽어보는 곳. 공시 원문으로 사례를 따라가고 시장데이터로 큰그림을 보려합니다.

증권신고서와 대량보유 보고서 같은 공시 원문을 한 줄씩 따라가며 개별 사례를 깊게 읽고, 거래소 데이터로 시장 전체의 큰그림을 봅니다. 인상이 아니라 원본으로 확인한 것만 쓰고, 어려운 제도는 쉬운 말로 풀어 씁니다.

- **IPO를 펼쳐보면**: 증권신고서를 펼쳐 회사가 스스로 적어 둔 위험, 주주와 맺은 계약, 상장을 서두른 사정을 읽습니다.
- **지분공시로 따라간 딜**: 흩어진 지분공시를 날짜순으로 이어 붙여 하나의 딜을 처음부터 끝까지 따라갑니다.
- **데이터로 들여다본 시장**: 거래소 데이터로 시장의 큰그림을 봅니다.
